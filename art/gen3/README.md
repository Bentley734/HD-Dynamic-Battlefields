# Hoenn source artwork

Organized as `size/location/`, with exact prompts and individual authoring
records beside every source image. Independent mounds stay under `art/mounds/`.

The initial Hoenn target is one variation per battle environment, with nine
aspect families and separate original outdoor day/night paintings. Existing
Kanto/Johto scenes are reused only where their environment is suitable.

Ashfield currently has 18 reviewed source candidates: day/night for all nine
aspects. The built-in image generator produced separate compositions. The
32:9 candidates received approved crop-only preparation; originals remain in
`drafts/32x9/`. Nothing was stretched, and no night painting is a darkening filter.

Source metadata contains provisional placement geometry, not gameplay-calibrated
anchors. These files are not yet in the published download index. See
`docs/GEN3-HOENN-DEVELOPMENT.md` for integration scope and validation evidence.
