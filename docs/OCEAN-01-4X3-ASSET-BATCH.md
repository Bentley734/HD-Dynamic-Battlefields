# Ocean first variation: classic display

Original dedicated 4:3 day/night paintings made with built-in ImageGen. Unchanged sources saved as `art/source/ocean-01-4x3.png` and `art/source/ocean-01-4x3-night.png`. Exact matching prompts retained under `art/prompts`.

Both visually inspected: high horizon, distant islands, open water through both standing regions, no baked mounds. Each period is independently painted. Catalog registration uses 4:3 metadata and independent grass-islet day/night materials. This adds no renderer or map-rule changes.

Remaining ocean aspect families and second/third variation counterparts are unfinished. Native grounding, blending, viewport behavior and release validation are untested. No tests, packaging or publication performed; battle UI, sprite defaults and Alpha 6 mound sizing remain unchanged.
