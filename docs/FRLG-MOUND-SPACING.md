# FR/LG mound spacing correction

The native FR/LG player mound is raised three game pixels and the opponent mound lowered two game pixels. Sprite positions and battle UI are unchanged. Existing user offsets remain additive.

Checked with runtime 0.3.95 in FireRed and LeafGreen using the official mod loader, National Dex, G9 sprites and HD sprite library: 12 native scene checks per game at 1280x720. These isolated checks do not constitute a full live playthrough.

This code-only beta reuses the published beta.1 artwork index; existing downloaded artwork does not need to be downloaded again. Unpublished artwork remains outside this release.
