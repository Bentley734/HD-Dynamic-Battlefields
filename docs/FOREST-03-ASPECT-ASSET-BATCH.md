# Forest variation 3 — remaining display families

Sixteen separate original day/night paintings complete local source registrations for all three forest variations across nine display families. The airy autumn silver-birch grove has a leaf-covered clearing, low fern bank and copper/gold foliage; the earlier forest sources, including the user's preferred first result, remain untouched.

Generated using the built-in image generator. Exact prompts and unchanged originals are retained in art/prompts and art/source. Visual review found single scenes, clear floor areas and no baked-in mounds or UI. Independent autumn day/night mounds are selected.

Several generated fern banks were too low. Aspect-correct authored regions raise them without stretching: 4:3 day/night y160; 16:10 day y40/night y160; 3:2 day y80/night y220; 21:9 both y160. Each region ends at the source bottom and has centered matching aspect width. Night landscape regions remove the moon completely rather than clipping it. 32:9 uses full width day2115/night2098, both starting y140, with heights594.84375/590.0625. Portrait 9:16 night starts y200; 9:19.5 day starts y100; other portrait regions are centered exact-aspect fits. Original source dimensions are recorded by the preparation work; requested tall formats sometimes returned wider compositions, so final native framing remains mandatory.

Horizon and mound contact are drafts pending combined native review, including 5120×1440. No tests, packaging or release publication were performed. Native sprites, battle UI and extra location artwork were preserved.
