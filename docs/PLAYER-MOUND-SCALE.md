# Player mound scale presets

Open HD Battlefields > Mounds > Player > Scale Preset. Choose 1X (normal) or 2X (double width and height).

The preset uses the existing adjustment scope: global, current aspect ratio, or current background. It changes only player mound scale, retaining mound/sprite offsets and opponent settings. The fine Mound Scale control remains available and is shown as CUSTOM when it differs from a preset. Existing saved values are retained until you choose a preset.

Validation: persistence callback and scoped settings checks, full Lua unit suite. This code-only beta reuses the existing published artwork index and adds no unfinished artwork.
