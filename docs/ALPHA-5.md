# Alpha 5 — doubled player mound

Player mound default width and height are twice Alpha 1–4: logical bounds 140×40 instead of 70×20. The native contact anchor stays at 36,96. Enemy mounds retain the doubled 110×32 bounds from Alpha 3. Existing user scales remain multiplicative. Native Pokémon and battle UI do not move; the panel may cover part of the larger player mound.

Validation uses the 13 pure Lua checks and official v0.3.88 native Red renderer with Menu Customizer 3.35.4: river alignment at standard, super-ultrawide and portrait viewports, plus grassland day/night variation renders at the same viewports. Scenery rendering preserves native sprite/UI calls and transforms. This is isolated-fixture evidence, not complete live gameplay or sprite-mod compatibility.

All Alpha 4 artwork and limitations remain. The full ZIP is a complete alpha installation; the small Alpha 4→5 patch is only for an existing Alpha 4 installation. Close the game and merge the patch folder into the existing mod folder, allowing its files to replace the previous versions. Do not use the patch as a standalone mod.
