# Gen 2 integration status

The first-variation review catalog is generated by `tools/build_gen2_catalog.py`
from `metadata/gen2-reuse-plan.json`, saved authoring records and explicit mound
candidates in `metadata/gen2-mound-bindings.json`. Its output is
`metadata/gen2.lua`: 477 compositions covering 53 environment families and all
nine aspect families. It references existing Gen 1 paintings rather than copying
them. Source SHA-256 values and referenced texture paths are checked during
assembly. Mound choices remain candidates, not approved visual matches.

The working `main.lua` now selects this catalog for Gen 2. The read-only context adapter
reads the native Gen 2 screen's logic battle, fishing battle type, World surf
state, in-game time and weather. Exact per-game map signatures are generated in
`metadata/maps/gen2.lua` (161 Gold, 161 Silver, 163 Crystal). The classifier
separates land/surf/fishing and rejects unknown or modified signatures. Water
assignments now include routes, city ponds and coastal towns; catalog reuse
therefore also includes existing ocean and river paintings. The map exporter
rejects positive imported water rates without both water encounter mappings.

The Gen 2 scene insertion hook replaces only implicit full-screen paper within
the native draw scope, preserving explicit palette effects and HUD fills. It
paints at the final target size and relays transparent logical canvases without
reducing HD artwork to their pixel grid. Classic contacts follow the native
6x6 and 7x7 picture boxes; wide contacts apply WideBattle's 72px field translation.
Species offsets wrap only the existing picture call with a scoped translation.

Provider and graphics-spy tests pass for classic/wide paths, native fallback,
clock-based night selection, fishing habitat, explicit HUD/effect fills and
exception cleanup. Actual live animation rendering, Menu Customizer coexistence,
mound fit, color/contact review and gameplay calibration remain outstanding.
No new release is implied.

## Native GPU fixtures (2026-10-18)

`tools/gen2_probe` loads the imported Gold, Silver or Crystal data and the
downloaded v0.3.89 native battle logic/screen in an isolated LÖVE process.
It constructs a temporary Route 29 wild battle and never writes a game save.
All three versions render classic 1920x1080, wide 5120x1440 and portrait
900x1600 successfully. Disabled/enabled classic HUD, picture and panel method
call order and transforms are identical. Captures and reports are under
`docs/evidence/gen2/`. Crystal captures were visually reviewed for full-window
coverage and native contact-slot grounding; fixture initialization uses nearest
texture filtering and the normal visible HUD state.

This is native renderer fixture evidence, not map traversal, animation coverage,
all-location calibration or Menu Customizer compatibility. The next visual
batch must include distinctive interiors, water/night scenes and animations.

## Independent night framing

An optional `night_metadata` composition field identifies the perspective record
for a separately composed night painting. Entries without this field keep their
existing geometry. Scene preparation resolves the selected period's metadata
before loading textures and retains the previous scene when resolution fails.
Asset packs include night metadata and its inherited templates, validate its
identity/aspect, and namespace its reference when installed. This prevents night
paintings from inheriting unrelated day standing points.

## Validation performed

`tools/run_unit_tests.py` now accepts `--engine` and defaults to the downloaded
v0.3.89 engine source. The complete pure-Lua suite passes, including the Gen 2
catalog through the actual pack validator with PNG headers read from all
referenced textures. Missing night metadata and mismatched night aspects are
rejected. Scene checks verify that period changes select different standing
anchors and failed night metadata retains the working day scene.

These checks establish data validity and existing behavior regression coverage;
they do not establish visual mound fit, gameplay support or device performance.
