# Download size and variation choices

Asset Manager offers each artwork aspect ratio separately. Select Aspect Filter (or Automatic for the current display), Quality Filter, then Variations. One Per Area is the space-saving choice: one stable composition per distinct environment in that aspect pack, with its own metadata, independent mounds and separate day/night artwork where applicable. All Variations includes every available variation for that aspect. Neither choice requires downloading other aspect ratios.

Mobile, HD and Ultra-HD remain separate quality filters; only tiers with real published assets appear. Pack details show installed byte size. Multiple aspect packs can be installed together. Remove an installed full pack to reclaim its space after replacing it with the one-per-area pack; downloading a smaller pack does not implicitly delete an existing pack.

The pack builder emits distinct identifiers and descriptors for both variation profiles for each available aspect/tier. Publication and end-to-end downloader validation are still pending.
